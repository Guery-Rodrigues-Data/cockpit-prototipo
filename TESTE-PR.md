# PR de teste (demonstração do fluxo)

Este Pull Request existe só para mostrar como o projeto funciona. **Não fazer merge**; pode ser fechado depois da demonstração.

Fluxo usado no projeto:

1. Partir do `main` atualizado e criar uma branch curta (`produto/…`, `ux/…`, `teste/…`).
2. Fazer a alteração e o commit na branch. Ninguém commita direto no `main`.
3. Abrir o Pull Request: a Vercel gera um link de prévia do site com a alteração.
4. Revisão no PR.
5. Merge no `main`: a Vercel publica.

Esta alteração é só este arquivo e não muda nada no cockpit.
